INSTRUCOES NO APLICATIVO DO MONGODB PARA A APLICACAO FUNCIONAR

Importante:
- Com o docker-compose atual, os bancos e colecoes podem ser criados automaticamente na primeira gravacao.
- Mesmo assim, se voce estiver usando o MongoDB Compass ou MongoDB Atlas, siga estas instrucoes para conferir e preparar o ambiente.

1. Criar o acesso ao MongoDB
- Se estiver usando MongoDB Atlas, crie um cluster.
- Crie um usuario de banco com permissao readWrite.
- Libere o IP da maquina que vai rodar a aplicacao.
- Copie a string de conexao.

2. Conferir os bancos esperados
A aplicacao espera tres bancos separados:
- aps_health_cadastro
- aps_health_agendamento
- aps_health_faturamento

3. Conferir as colecoes esperadas
No banco aps_health_cadastro:
- pacientes
- medicos
- especialidades
- consultorios
- medicamentos
- exames
- counters

No banco aps_health_agendamento:
- consultas
- escalas
- solicitacoes
- counters

No banco aps_health_faturamento:
- valores
- pagamentos
- cobrancas
- counters

4. O que precisa existir no MongoDB App
- Um usuario valido para conexao.
- Permissao para criar bancos e colecoes.
- Acesso liberado para a maquina da aplicacao.
- Se estiver usando MongoDB local fora do Docker, a porta padrao normalmente e 27017.

5. Ajustar a string de conexao, se necessario
- Se voce usar o MongoDB local do docker-compose, as variaveis ja estao preparadas para os containers.
- Se voce usar Atlas ou outro servidor externo, troque o MONGO_URI de cada servico para a string correta.

6. Conferencia apos a aplicacao subir
Depois de iniciar a aplicacao:
- abra o MongoDB Compass;
- conecte no cluster ou instancia;
- confira se os bancos foram criados;
- confirme se as colecoes aparecem apos o primeiro cadastro.

7. Observacao importante
- Os ids sao controlados pela colecao counters.
- Nao apague a colecao counters se quiser manter a sequencia dos registros.
- Se apagar, os proximos cadastros podem reiniciar a contagem.
