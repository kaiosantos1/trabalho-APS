# Frontend APS Health

Frontend inicial em HTML, CSS e JavaScript puro.

Para testar, é necessário deixar o Cadastro Service rodando em:

http://localhost:5001

Depois, abrir o arquivo index.html no navegador.

Funcionalidades atuais:

- Cadastrar e listar especialidades
- Cadastrar e listar pacientes
- Cadastrar e listar médicos

Plano para o front end integrado:


----AdministradorPage: ----
--Cadastro Service--
-Cadastro de médicos 
-cadastro de especialidades
--agendamento service--
-Aprovar ou reprovar solicitações de cancelamento de agendamento
-Resolver
--faturamento service--
-emitir fatura
-cobrar consulta

---- UsuarioPage: ----
--Cadastro service--
-Se Cadastrar
--Agendamento service--
-marcar consulta
-editar consulta
-remarcar consulta
-Solicitar cancelamento de consulta

---- MedicoPage: ----

---- Login page ----
- Selecionar opção administrador - Já possui cadastro pré definido
- Selecionar opção de Usuario 
    - Caso ja tenha cadastro -> UsuarioPage
    - Caso contrário -> CadastroPage -> paginaUsuario

---- Integração ----

- Preparar para integração com MongoDB
